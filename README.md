# Palace TUI

A terminal-based personal knowledge graph builder that automatically extracts entities and relationships from your notes, lets you explore connections visually, and helps you discover insights you didn't know you had.

## Features (Planned)

- **Privacy-first**: All processing happens locally
- **Markdown-native**: Works with your existing notes
- **Auto-linking**: Discovers connections automatically
- **Terminal UI**: Stay in your workflow
- **Fast**: Built with Rust for performance

## Status

**Phase 1 (In Progress)**: Core infrastructure
- [x] Project setup
- [ ] Note ingestion engine
- [ ] Storage layer
- [ ] Basic TUI skeleton

## Quick Start

```bash
# Build and run
cargo run

# Run tests
cargo test
```
